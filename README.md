### 🔁 WooCommerce → Shopify Refund Order Sync

* Developed an automated workflow to sync **refund orders from WooCommerce to Shopify** in real time.
* Integrated both platforms via APIs to transfer refund details, line items, taxes, and payment status accurately.
* Implemented validation checks to prevent duplicate or mismatched refund records.
* Ensured inventory and financial data remained consistent across both platforms.

**Impact:**

* Eliminated manual refund reconciliation
* Improved financial accuracy and reporting consistency
* Reduced operational errors in multi-platform store management

**Tech Stack:**
WooCommerce API • Shopify API • Make.com / Automation Tools • Webhooks • Data Synchronization
